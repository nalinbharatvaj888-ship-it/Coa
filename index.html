01 — Foundation

What is COA?

Computer Organization and Architecture (COA) studies how a computer is designed and how its internal components work together to execute instructions. The CPU, memory, I/O devices and buses form a connected system. The CPU repeatedly fetches instructions, decodes them and executes them.

Architecture

Describes what the programmer can see: instruction set, registers, addressing modes and system behavior.

Organization

Describes how the hardware implements that architecture: ALU, control unit, buses, memory and control signals.

Goal

Understand how bits become instructions, how instructions are processed, and how hardware components communicate.

02 — The Brain

CPU: Central Processing Unit

ALU — Arithmetic Logic Unit

Performs arithmetic and logical operations such as addition, subtraction, AND, OR and comparisons.

CU — Control Unit

Decodes instructions and generates control signals that coordinate the movement and processing of data.

Registers

Very fast storage locations inside the CPU. Examples include the Program Counter (PC), Instruction Register (IR), MAR and MDR.

04 — Memory

Memory Hierarchy

Memory is organized in levels to balance speed, capacity and cost. Generally, the closer memory is to the CPU, the faster and smaller it is.

REGISTERS — fastest, very small
CACHE — very fast, small
RAM — main working memory
SECONDARY STORAGE — SSD / HDD, large and persistent
05 — Instruction Processing

Fetch → Decode → Execute → Store

1. Fetch

The CPU obtains the next instruction from memory using the address held by the Program Counter.

2. Decode

The Control Unit interprets the instruction and determines what operation is required.

3. Execute

The required operation is performed, often using the ALU and CPU registers.

4. Store

The result is placed in a register or memory when required, and the cycle continues.

08 — Example

How an ADD Instruction Works

Suppose register R1 contains 5 and R2 contains 3. An ADD instruction asks the CPU to calculate 5 + 3.

R1 = 5 R2 = 3 Instruction = ADD R1, R2 ALU → 5 + 3 = 8 Result → R1 = 8

This small example represents the same fundamental sequence used by much more complex programs: instructions are fetched, interpreted and executed by the processor.

09 — Conclusion

From Bits to Processing

A computer works because its components cooperate. The CPU performs operations, memory stores information, buses carry data and control signals, and I/O devices allow interaction with the outside world. The instruction cycle provides the basic rhythm of processing.

Key Takeaway

CPU + Memory + I/O + Buses form the core organization of a computer system.

Learning Outcome

After exploring this project, a student can trace how an instruction travels from memory to the CPU and becomes a result.
