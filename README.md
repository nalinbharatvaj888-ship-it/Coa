## 📌 Overview

Computer Organization & Architecture (COA) explains how the internal components of a computer work together to execute instructions.

This project converts important COA concepts into an interactive web-based learning experience.

The project covers:

- CPU
- ALU
- Control Unit
- Registers
- Memory Hierarchy
- System Bus
- Instruction Cycle
- Fetch → Decode → Execute → Store
- Basic CPU simulation

## ⚙️ Instruction Cycle Simulator

The project demonstrates the basic CPU instruction cycle:

### 1. FETCH
The CPU obtains the instruction from memory.

### 2. DECODE
The Control Unit interprets the instruction.

### 3. EXECUTE
The ALU performs the required operation.

### 4. STORE
The result is stored in a register or memory.

Example:

```text
Instruction → ADD R1, R2

R1 = 5
R2 = 3

ALU → 5 + 3 = 8

Result → R1 = 8
